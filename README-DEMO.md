# SKY Coffee House — جاهز للتجربة

هذه النسخة تعمل فوراً بدون إعداد Supabase.

### تجربة الطلب
1. افتح `index.html?table=1`.
2. أضف أي صنف إلى السلة.
3. اضغط **تأكيد الطلب**.
4. افتح `management/kitchen.html` في تبويب آخر من **نفس المتصفح وعلى نفس الرابط/الدومين**.
5. سيظهر الطلب في **New Orders** ويمكن تحريكه إلى Cooking ثم Ready ثم Served.

### دخول الإدارة
- البريد: `admin@skycoffee.com`
- كلمة المرور: `SKY@2026`

### مهم
الوضع الموجود هنا هو **Demo Mode**: الطلبات محفوظة محلياً في المتصفح. للمطعم الحقيقي بحيث هاتف الزبون يرسل الطلب إلى لابتوب المطبخ عبر الإنترنت، يلزم ربط Backend/قاعدة بيانات سحابية (مثل Supabase). الملف الأصلي لا يحتوي بيانات مشروع سحابية، لذلك لا يمكن اختراعها أو تضمينها من عندنا.
